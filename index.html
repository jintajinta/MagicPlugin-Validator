MagicPlugin Validator

MagicPlugin の wand / spell YAML を検証します。

Magic は書き間違いを警告しません。未知のキーも無効な enum 名も黙って無視され、「なぜか何も起きない」になります。 このページはそれを配置前に見つけます。検証はブラウザ内で完結し、ファイルはどこにも送信されません。

    深刻度について

    レベル意味対応
    ✗ エラー 存在しない Particle / Sound / Material、wand の無効キー、不明な EffectLib クラス、alt_castN の番号ずれ 必ず潰す。その行は確実に効かない
    ⚠ 重要 構文は正しいのに黙って実害が出る。値が切り捨てられる、併記した片方が無視される、耐久で壊れる など 必ず潰す。エラーが出ないぶんこちらの方が危険
    ! 警告 タイポの疑い、推奨から外れている 見て判断する
    · 補足 参照データの機械抽出が漏れているかもしれない行 ソースを確認して有効なら無視してよい
    「⚠ 重要」で何を見ているか

    いずれも MagicPlugin のソースを読んで裏を取った判定です。例:

    • AreaOfEffect / LineOfEffect の radius は int に切り捨てられる（0.75 → 0 で当たらなくなる）
    • Velocity に min_speed / max_speed があると speed は無視される
    • CustomProjectile に velocity があると speed は無視される（単位も20倍違う）
    • CheckVelocity の min_speed は実装が max_speed と同じ向きで、意味が反転している
    • ConeOfEffect は radius を読まない（扇の広さは fov）
    • effects: の delay はミリ秒を整数除算するので 50 未満は 0tick になる
    • Damage の no_damage_ticks: 1〜10 は 0 と同じで多段ヒットを防げない
    • 技を持つ wand に indestructible が無いと耐久で壊れて消える

    参照データは MagicPlugin と EffectLib のソース、および Paper 1.21.8 の enum から生成しています。 Minecraft 1.21.8 / Paper 想定。
